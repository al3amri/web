Module 01 — Introduction to Ethical Hacking GENERAL ONLY · عام فقط
Honest note / ملاحظة مهمة: You did not send Module 01 text, so this section is standard CEH background only. If your doctor's slides differ, trust the slides. لم ترسل نص الوحدة ٠١، لذا هذا القسم خلفية عامة من CEH فقط — إن اختلفت شرائح الدكتور، اعتمد الشرائح.
1

Permission comes first

An ethical hacker is an authorised hacker: permission, scope, and Rules of Engagement (RoE) are agreed before any test. Without permission, the same actions can be illegal.

المخترق الأخلاقي يعمل بتصريح: يُتفق على الإذن والنطاق وقواعد الاشتباك قبل أي اختبار، وبدون إذن قد تكون نفس الأفعال غير قانونية.

2

Hat colours

White-hat: authorised, defensive. Black-hat: unauthorised, malicious. Grey-hat: in between, no clear permission.

القبعة البيضاء: مصرح ومدافع. السوداء: غير مصرح وخبيث. الرمادية: بينهما دون إذن واضح.

3

The hacking phases, in order

Reconnaissance → Scanning → Gaining Access → Maintaining Access → Clearing Tracks. This midterm covers the first two phases plus enumeration and vulnerability analysis.

مراحل الاختراق بالترتيب: الاستطلاع ← الفحص ← الوصول ← الحفاظ على الوصول ← محو الآثار. هذا الاختبار يغطي أول مرحلتين مع التعداد وتحليل الثغرات.

Question that may come · السؤال المتوقع

  • MCQ: Which phase comes first / what makes hacking "ethical"? → Reconnaissance; authorisation + scope + RoE.
  • اختيار من متعدد: ما أول مرحلة؟ وما الذي يجعل الاختراق أخلاقياً؟ ← الاستطلاع؛ والتصريح والنطاق وقواعد الاشتباك.
Module 02 — Footprinting & Reconnaissance FROM YOUR LABS · من مختبراتك
1

Agree scope + RoE, then build the "footprint"

Reconnaissance is step 1 of any attack: collect information to build a blueprint ("footprint") of the organisation — organisation info (employees, partners, technologies), network info (domains, subdomains, IPs, Whois, DNS), and system info (OS, servers).

الاستطلاع هو الخطوة الأولى: اجمع المعلومات لبناء بصمة/مخطط للمنظمة — معلومات المنظمة (موظفون وشركاء وتقنيات)، والشبكة (نطاقات وعناوين IP وسجلات DNS)، والأنظمة (نظام التشغيل والخوادم). وقبلها اتفق على النطاق وقواعد الاشتباك.

2

Passive vs Active — know the difference cold

Passive: NO direct interaction with the target — used when you must not be detected. Active: direct interaction — the target may recognise the gathering.

سلبي: بدون تفاعل مباشر مع الهدف — عندما يجب ألا تُكتشف. نشط: تفاعل مباشر — وقد يلاحظ الهدف عملية الجمع.

3

Domains & subdomains: Netcraft + DNSdumpster

Netcraft → Resources → Research Tools → Site Report ("What's that site running?") gives background, network, hosting history. DNSdumpster gives GeoIP, DNS servers, MX records, Host (A) records and a domain map for e.g. certifiedhacker.com.

موقع Netcraft (تقرير الموقع) يعطي الخلفية والشبكة وسجل الاستضافة، وDNSdumpster يعطي الموقع الجغرافي وخوادم DNS وسجلات MX وA وخريطة النطاق.

4

People: Sherlock on social networks

sudo su # Parrot, run as root (lab password: toor) sherlock "Elon Musk"

Sherlock searches many social networking sites for a person/username and returns the profile URLs — names, positions, locations, employers — fuel for social engineering.

يبحث Sherlock في مواقع تواصل كثيرة عن شخص أو اسم مستخدم ويعرض روابط حساباته — أسماء ومناصب ومواقع وجهات عمل — وهي مادة للهندسة الاجتماعية.

5

Whois footprinting — DomainTools

Whois = query/response protocol on TCP port 43; databases are kept by Regional Internet Registries (RIRs). A lookup reveals owner, registrar, creation/expiry dates, name servers, contacts.

Whois بروتوكول استعلام على المنفذ TCP 43 وقواعده لدى سجلات الإنترنت الإقليمية RIR. يكشف المالك والمسجّل وتواريخ التسجيل والانتهاء وخوادم الأسماء وجهات الاتصال.

6

DNS footprinting with nslookup — the exact lab sequence

nslookup # shows default server, e.g. dns.google 8.8.8.8 set type=a www.certifiedhacker.com # → 162.241.216.11 (non-authoritative!) set type=cname certifiedhacker.com # → authoritative NS: ns1.bluehost.com set type=a ns1.bluehost.com # → IP of the name server itself

Why "non-authoritative"? The answer came from your local/Google resolver, not from the domain's own authoritative server. AAAA = IPv6 query type.

لماذا الجواب «غير موثوق»؟ لأنه جاء من المُحلّل المحلي/جوجل وليس من خادم النطاق الرسمي نفسه. وAAAA هو نوع استعلام IPv6.

7

Network footprinting: traceroute

tracert www.certifiedhacker.com # Windows tracert -h 5 www.certifiedhacker.com # -h = maximum hops (here 5) traceroute www.certifiedhacker.com # Linux / Parrot

Reveals the path packets take: intermediate hosts, network topology, trusted routers, firewall locations.

يكشف مسار الحزم: الأجهزة الوسيطة وطوبولوجيا الشبكة والموجهات الموثوقة ومواقع الجدران النارية.

8

Email footprinting: eMailTrackerPro

Paste a full email header (Gmail: ⋯ → Show original; Outlook: View message source) and trace it: sender IP, geolocation, mail server, hops, OS/browser, read time.

الصق ترويسة البريد الكاملة (في Gmail: إظهار الأصل) وتتبّعها: عنوان المرسل وموقعه وخادم البريد والقفزات ونظام التشغيل والمتصفح.

9

Recon-ng — the framework workflow

recon-ng marketplace install all workspaces create CEH db insert domains # → certifiedhacker.com modules load recon/domains-hosts/brute_hosts run # harvest hosts; then show hosts modules load recon/domains-contacts/whois_pocs # personnel/contacts module options set SOURCE facebook.com run

Also: bing_domain_web, reverse_resolve, hackertarget modules, and reporting/html to export results.html.

إطار عمل للاستطلاع: أنشئ مساحة عمل، أضف النطاق، حمّل الوحدات وشغّلها لحصد الأجهزة وجهات الاتصال، ثم صدّر تقرير HTML.

Module 03 — Scanning Networks ICMP QUESTION LIVES HERE · سؤال ICMP هنا
1

Three types of scanning

Port scanning = open ports & services. Network scanning = live hosts & IPs. Vulnerability scanning = known weaknesses. Scanning is extended reconnaissance — not yet intrusion.

ثلاثة أنواع: فحص المنافذ (منافذ وخدمات مفتوحة)، فحص الشبكة (أجهزة حية وعناوين)، فحص الثغرات (نقاط ضعف معروفة). الفحص استطلاع موسّع وليس اختراقاً بعد.

2

Host discovery: -sn = "is it up?" only

-sn disables the port scan. Lab targets: 10.10.1.22 = Windows Server 2022 · 10.10.1.11 = Windows 11 · 10.10.1.19 = Server 2019 · 10.10.1.13 = Parrot.

CommandTechnique"Alive" signal
nmap -sn -PR <IP>ARP pingARP response

nmap -sn -PE 10.10.1.10-23ICMP ECHO ping SWEEPECHO replies from the range

3

Port scans — flags and what the reply means

CommandScanKey idea
nmap -sT -v <IP>TCP connect / full openFull handshake SYN → SYN+ACK → ACK, then RST
nmap -sS -v <IP>Stealth / half-openRST before handshake completes — harder to log
nmap -sX -v <IP>XmasFIN+URG+PUSH set · open/filtered = no reply · closed = RST
nmap -sM -v <IP>MaimonFIN/ACK probe · no reply = open|filtered · RST = closed
nmap -sA -v <IP>ACK probeNo reply = filtered (stateful FW) · RST = unfiltered
nmap -sU -v <IP>UDPSlow (~15–20 min) · no reply = open · ICMP unreachable = closed
nmap -sV <IP>Version detectionService versions → which exploits may work
nmap -A <IP>Aggressive= -O + -sV + -sC + --traceroute · permission only!

احفظ الفرق: -sT يكمل المصافحة كاملة، و-sS يقطعها قبل اكتمالها (نصف مفتوح). في Xmas: لا رد = مفتوح/مصفّى، وRST = مغلق. و-A يجمع كشف النظام والإصدارات والسكربتات والتتبع.

4

OS discovery / banner grabbing

nmap -O <IP> # OS discovery only nmap -A <IP> # aggressive: OS + names + more nmap --script smb-os-discovery.nse <IP> # via SMB 445/139: OS, computer, domain, workgroup, time

Active grabbing: crafted packets, compare replies to a database. Passive: error messages, sniffing, page extensions. TTL + TCP window size in the first packet help identify the OS.

الالتقاط النشط: حزم مصنوعة ومقارنة الردود بقاعدة بيانات. السلبي: رسائل خطأ وتنصّت وامتدادات صفحات. وقيمتا TTL وحجم نافذة TCP في أول حزمة تساعدان على معرفة النظام.

5

Scanning beyond IDS / firewall

nmap -f 10.10.1.11 # -f = fragment packet into tiny pieces nmap -g 80 10.10.1.11 # source-port manipulation: pretend port 80 nmap -mtu 8 10.10.1.11 # tiny 8-byte MTU packets nmap -D RND:10 10.10.1.11 # 10 random decoy IPs hide your real IP

Other evasion ideas from the module: source routing, IP spoofing, custom packets, random host order, bad checksums, proxies, anonymizers. Wireshark filter for fragments: ip.fragment.

تقنيات تجاوز الجدار ونظام كشف التسلل: التجزئة (-f)، والتلاعب بمنفذ المصدر (-g 80)، وحزم MTU صغيرة، وعناوين شركية عشوائية (-D RND:10) لإخفاء عنوانك الحقيقي.

6

Module 04 — Enumeration FROM YOUR LABS · من مختبراتك
1

What enumeration is

Enumeration = active connection + directed queries, inside the intranet. It extracts users, groups, shares, machine names, OSes, services, routing tables, policies. ⚠ It may be illegal without proper authorisation.

التعداد = اتصال نشط واستعلامات موجّهة داخل الشبكة الداخلية. يستخرج المستخدمين والمجموعات والمشاركات وأسماء الأجهزة والخدمات وجداول التوجيه. وقد يكون غير قانوني بدون تصريح.

2

NetBIOS enumeration (ports 137/138/139)

nbtstat -a 10.10.1.11 # NetBIOS name table of the REMOTE computer nbtstat -c # NetBIOS name cache (names + resolved IPs) net use # connections & shared folders/drives

A NetBIOS name is 16 characters: first 15 = device name, 16th = service/record type. Exploitable even when not in use; a name table can be read without a null session.

اسم NetBIOS مكوّن من ١٦ حرفاً: أول ١٥ للجهاز والحرف ١٦ لنوع الخدمة/السجل. والأمر -a يعرض جدول أسماء الجهاز البعيد، و-c يعرض الذاكرة المؤقتة للأسماء.

3

SNMP enumeration (UDP 161/162) — SnmpWalk

snmpwalk -v1 -c public 10.10.1.22 snmpwalk -v2c -c public 10.10.1.22

SNMP = application-layer protocol over UDP; an agent runs on the device, a management station talks to it. -v = version, -c = community string — that exact point is lab question 4.2.1.1.

SNMP بروتوكول طبقة تطبيقات فوق UDP: وكيل على الجهاز ومحطة إدارة تتحدث معه. الخيار -v للإصدار و-c لسلسلة المجتمع — وهذه نقطة سؤال مختبر بعينها.

4

LDAP enumeration (TCP 389) — AD Explorer

LDAP connects to a DSA (Directory System Agent), uses BER encoding, and can be queried anonymously for usernames, addresses, departments, server names. In AD Explorer: connect to 10.10.1.22 → expand DC=CEH, DC=com, CN=Users → view/modify attributes like displayName.

LDAP على المنفذ TCP 389 يتصل بوكيل دليل DSA ويستخدم ترميز BER، ويمكن استعلامه دون مصادقة للحصول على أسماء المستخدمين والعناوين والأقسام وأسماء الخوادم.

5

NFS enumeration — port 2049

nmap -p 2049 10.10.1.19 # is NFS open? python3 rpc-scan.py 10.10.1.19 --rpc # RPCScan: --rpc lists RPC / portmapper

NFS lets a client use remote files as if local. SuperEnum also enumerates port 2049; RPCScan lists RPC services, mountpoints and NFS-accessible directories.

NFS على المنفذ 2049 يتيح استخدام ملفات بعيدة كأنها محلية. وأمر RPCScan مع --rpc يعرض خدمات RPC ونقاط التحميل والمجلدات المتاحة.

6

DNS enumeration — zone transfer

dig ns www.certifiedhacker.com dig @ns1.bluehost.com www.certifiedhacker.com axfr # axfr = zone transfer attempt

Lab result: Transfer failed — and in nslookup (set querytype=soa → ls -d ns1.bluehost.com) it was refused. So: can you zone-transfer certifiedhacker.com's primary host? No. The SOA record holds the primary NS + responsible mail address.

نقل المنطقة axfr: نتيجة المختبر «فشل النقل» و«رُفض» — إذن الجواب: لا يمكن نقل منطقة المضيف الأساسي لهذا النطاق. وسجل SOA يحمل خادم الأسماء الأساسي وعنوان البريد المسؤول.

7

SMTP enumeration (TCP 25, also 2525/587) — Nmap NSE

nmap -p 25 --script=smtp-enum-users 10.10.1.19 # list possible mail users nmap -p 25 --script=smtp-open-relay 10.10.1.19 # open relays nmap -p 25 --script=smtp-commands 10.10.1.19 # available SMTP commands

Why it matters: a list of valid users enables password spraying. Global Network Inventory is the module's agent-free audit scanner (tabs: OS, BIOS, NetBIOS, users, groups, services, shares…).

تعداد SMTP يكشف المستخدمين الصالحين — وهذا يمكّن هجوم رشّ كلمات المرور. وأداة Global Network Inventory ماسح تدقيق بلا وكيل يعرض النظام والمستخدمين والخدمات والمشاركات.

Module 05 — Vulnerability Analysis FROM YOUR LABS · من مختبراتك
1

What a vulnerability is

A weakness in design or implementation that can be exploited, often to bypass authentication. Causes: misconfiguration and poor programming. An assessment recognises, measures and classifies: missing patches, unnecessary services, weak authentication/encryption, weak permissions, default apps.

الثغرة ضعف في التصميم أو التنفيذ يمكن استغلاله، غالباً لتجاوز المصادقة. أسبابها: سوء الإعداد والبرمجة الضعيفة. والتقييم يحدد ويقيس ويصنف: تحديثات مفقودة وخدمات زائدة ومصادقة وتشفير ضعيفان وأذونات ضعيفة.

2

The three databases — don't mix them up

CWE = categories of software weakness types (baseline for identification/mitigation). CVE = individual named vulnerabilities. NVD = US database built on CVE with scoring/details. Lab example clicked: CWE-284 Improper Access Control.

لا تخلط بينها: CWE تصنيف لأنواع نقاط الضعف، وCVE ثغرات فردية مسماة، وNVD قاعدة أمريكية مبنية على CVE مع التقييم والتفاصيل.

3

Two facts to say out loud tonight

CWE-591 = Sensitive Data Storage in Improperly Locked Memory 2023 CWE Top 25 #1 = CWE-787 Out-of-bounds Write #2 = CWE-79 Cross-site Scripting (XSS) #3 = CWE-89 SQL Injection

حقيقتان احفظهما حرفياً: CWE-591 هو تخزين بيانات حساسة في ذاكرة مقفلة بشكل غير صحيح، ورقم ١ في قائمة CWE Top 25 لعام ٢٠٢٣ هو CWE-787 الكتابة خارج الحدود.

4

OpenVAS — step by step

docker run -d -p 443:443 --name openvas mikesplain/openvas # Browser → https://127.0.0.1/ → login admin / admin # Scans → Tasks → Task Wizard → target 10.10.1.22 → Start Scan

Wait ~15–20 min: Status Requested → Done → click Done → Report: Results (vulnerability, severity, port). NVT feed = 50,000+ tests; supports unauthenticated + authenticated testing. Lab point: re-scanning with Windows Firewall ON gave the same results — a firewall alone did not hide the vulnerabilities.

شغّل OpenVAS بالأمر أعلاه، سجّل دخول admin/admin، أنشئ مهمة فحص للهدف 10.10.1.22 وانتظر «تم» ثم افتح النتائج (الثغرة وخطورتها والمنفذ). نقطة المختبر: إعادة الفحص مع تشغيل الجدار الناري أعطت نفس النتائج.

5

ShellGPT vulnerability tools

sgpt --chat nikto --shell "Scan the URL https://www.certifiedhacker.com to identify potential vulnerabilities with nikto" sgpt --chat vuln --shell "Perform a vulnerability scan on target url http://testasp.vulnweb.com with skipfish" # skipfish report → /tmp/skipfish_scan_output/index.html · pause Nikto with Ctrl+Z

Assessment approaches: active scanning vs passive scanning.

أدوات عبر ShellGPT: Nikto لفحص موقع، وskipfish لفحص تطبيق ويب وتقريره في ملف index.html. ومنهجا التقييم: فحص نشط وفحص سلبي.

The ICMP drill تدريب ICMP — سؤال شاشة الأوامر

The doctor confirmed a command-screen question on ICMP. Learn this pattern: nmap -sn -P? — only the letter changes.

أكّد الدكتور سؤال شاشة أوامر عن ICMP. احفظ النمط: يتغير حرف واحد فقط بعد -P.

-PE — ECHO

nmap -sn -PE 10.10.1.22

Sends ICMP ECHO requests. Host alive → ICMP ECHO reply.

يرسل طلبات صدى ICMP. الجهاز حي ← يرد بصدى ICMP.

-PE + range — SWEEP

nmap -sn -PE 10.10.1.10-23

Same command on a range = ping sweep: finds all live hosts in the range.

نفس الأمر على نطاق = مسح ping: يجد كل الأجهزة الحية في النطاق.

-PP — Timestamp

nmap -sn -PP 10.10.1.22

Asks the host for its current time via an ICMP timestamp message.

يسأل الجهاز عن وقته الحالي برسالة طابع زمني ICMP.

-PM — Address Mask

nmap -sn -PM 10.10.1.22

The alternative to use when ECHO pings are blocked by the admin/firewall.

البديل الذي تستخدمه عندما تكون طلبات الصدى محجوبة.

Memory hook · وسيلة للحفظ

E = Echo · P (second P) = clock/time (timestamp) · M = Mask · R = ARP · U = UDP · S = SYN (reply: ACK) · A = ACK (reply: RST) · O = prOtocol. And -sn always means: no port scan, discovery only.

تذكّر: E للصدى، وM للقناع، وR لـ ARP، وU لـ UDP. و-sn تعني دائماً: بدون فحص منافذ، اكتشاف فقط.
